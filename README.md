# LightCast

> 📘 **처음 쓰시나요? [사용 설명서 (PDF) 다운로드](https://github.com/shrlak/LightCast/raw/main/docs/LightCast-Manual.pdf)** · [미리 보기](docs/LightCast-Manual.pdf)
>
> 설치 → 화면 보기 → 이번 주 예배 만들기 → 발표하기까지, 꼭 필요한 것만 11쪽에 담은 쉬운 안내서입니다. 맨 뒤 단축키 한 장 요약은 출력해서 컴퓨터 옆에 두세요.

KCCP 빛주사랑 대학청년부의 예배 프레젠테이션 앱입니다. 모든 슬라이드는 교회 PowerPoint와 같은 **4:3** 비율입니다. PowerPoint처럼 슬라이드를 편집하고, ProPresenter처럼 바로 발표하며, 주일예배 · 수련회 슬라이드를 교회 템플릿으로 만들어 줍니다.

## 다운로드

[**최신 버전 받기 → Releases**](https://github.com/shrlak/LightCast/releases/latest)

| 컴퓨터 | 받을 파일 |
| --- | --- |
| Mac (Apple Silicon · Intel 모두) | `LightCast-<버전>.dmg` |
| Windows 10 / 11 (일반 PC · ARM PC 모두) | `LightCast-Setup-<버전>.exe` |

Mac용 `.dmg` 하나가 Apple Silicon(M1 · M2 · M3 · M4)과 Intel Mac에서 모두 돌아가고, Windows용 `.exe` 하나가 일반(x64) PC와 ARM PC에 맞는 버전을 알아서 설치합니다.

> `.zip`, `.blockmap`, `latest.yml`, `latest-mac.yml` 파일은 자동 업데이트용입니다. 직접 받을 필요가 없습니다.

## 설치 방법

### Mac

1. `LightCast-<버전>.dmg` 파일을 받아서 엽니다.
2. 열린 창에서 **LightCast** 아이콘을 **Applications(응용 프로그램)** 폴더로 끌어다 놓습니다.
3. 처음 한 번만: **응용 프로그램** 폴더에서 LightCast를 **오른쪽 클릭(또는 Control-클릭) → 열기 → 열기**를 누릅니다.
   - 앱이 아직 Apple 개발자 인증서로 서명 · 공증되지 않아서 그냥 더블클릭하면 "확인되지 않은 개발자"(또는 "Apple은 악성 코드가 없음을 확인할 수 없습니다") 경고가 뜹니다.
   - 그래도 열리지 않으면(macOS 15 이상은 대부분 이쪽): 한 번 열어 본 뒤 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 "LightCast"에서 **그래도 열기**를 누르고 Mac 암호를 넣습니다.
4. 그다음부터는 평소처럼 더블클릭으로 열면 됩니다.

> **"LightCast이(가) 손상되었기 때문에 열 수 없습니다"가 뜨면** (0.7.6 이하 버전을 새로 받은 경우): 파일이 깨진 것이 아니라 그 버전의 앱에 서명이 없어서 macOS가 막는 것입니다. 0.7.7 이상을 받으면 위의 3번 방법으로 열립니다. 이미 받은 앱을 바로 열려면 **응용 프로그램 → 유틸리티 → 터미널**을 열고 아래 한 줄을 붙여 넣은 뒤 Return을 누르세요. 그다음 LightCast를 다시 열면 됩니다.
>
> ```
> xattr -cr /Applications/LightCast.app
> ```

### Windows

1. `LightCast-Setup-<버전>.exe` 를 받아서 실행합니다.
2. "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (앱이 아직 코드 서명되지 않았기 때문입니다.)
3. 설치 마법사를 따라 설치합니다. 바탕화면과 시작 메뉴에 LightCast가 생깁니다.

## 자동 업데이트

설치한 뒤에는 따로 다시 받을 필요가 없습니다. LightCast는 스스로 업데이트됩니다.

- 앱을 켠 직후, **앱이 열려 있는 동안 30분마다**, 그리고 컴퓨터가 잠자기에서 깨어날 때 새 버전이 있는지 확인합니다. 마지막으로 확인한 시각은 **⚙ 설정 → 일반**에 나옵니다.
- 새 버전이 있으면 **LightCast 화면 위쪽에 알림**(그리고 컴퓨터 알림)을 띄우고 뒤에서 내려받은 다음, **앱을 종료할 때 자동으로 설치**합니다. 다음에 켜면 새 버전입니다.
- 예배 중에는 절대 저절로 재시작하지 않습니다. 바로 설치하려면 알림이나 위쪽 배너의 **지금 재시작하여 업데이트**를 누르세요.
- 언제든 직접 확인하려면: Mac은 메뉴 **LightCast → Check for Updates…**, 또는 **⚙ 설정 → 일반 → 업데이트 확인**.

## 처음 쓸 때

- **화면 둘러보기**: 위쪽 탭은 7개이고, 기능마다 **한 곳에만** 있습니다 — **파일**(가져오기 · 백업 · 휴지통 · 기록), **홈**(슬라이드 · 프레젠테이션 · 재생목록에 넣기 · 찾기), **삽입**(슬라이드 템플릿 · 성경 검색 · 텍스트 · 그림 · 영상), **디자인**(테마 · 배경 · 화면 전환), **슬라이드 쇼**(처음부터 · 리허설 · 검은 화면 · 청중 화면 창 · X32 믹서 · 가사 따라가기), **예배**(이번 주 예배 · 예배 만들기 · 찬양 · 예배 전), **도구**(AI · 찬양 통계 · 저작권 보고). 맨 위 오른쪽에는 **휴대폰 · ☁ 계정 · ⚙ 설정 · ▶ 발표**가, 아래 상태 표시줄에는 **🔒 잠금**과 보기 전환(**기본 · 여러 슬라이드 · 발표자**)이 있습니다. 왼쪽 창은 **슬라이드 · 라이브러리 · 미디어**(배경 · 그림 · 영상 · 카메라)로 나뉩니다. 오른쪽 위 **⚙**는 설정으로, **일반 · 출력 화면 · 리모컨 · AI · 장비(X32 믹서 · 조명)** 페이지로 나뉘어 있습니다.
- **재생목록에 넣기 (이미 만든 재생목록에도)**: 세 가지 방법이 있습니다.
  - **검색해서 넣기**: **라이브러리** 탭 맨 위 재생목록의 검색창(또는 **슬라이드** 탭 맨 아래 **＋ 이 재생목록에 곡·자료 넣기**)에 곡 제목·가사를 치고 결과를 누르거나 Enter.
  - **골라서 넣기**: 라이브러리 항목의 **＋**, **홈 → 재생목록에 넣기**, 또는 슬라이드 오른쪽 클릭 → **재생목록에 넣기…**를 누르면 **모든 재생목록**이 나옵니다(지금 열린 재생목록이 맨 위). 다른 재생목록으로 바꾸지 않고 바로 넣을 수 있고, **＋ 새 재생목록 만들어 넣기**도 됩니다. 이미 들어 있는 재생목록에는 **✓ 있음**이 표시됩니다.
  - **끌어다 놓기**: 라이브러리 항목을 위쪽 재생목록의 원하는 자리에 끌어다 놓습니다. 재생목록 안의 항목도 끌어서 순서를 바꿉니다.
- **로그인 (선택)**: 오른쪽 위 **☁ 로그인 → 계정 만들기**에서 아이디·비밀번호와 **관리자 비밀번호**(주일예배 생성기의 관리자 설정과 같은 비밀번호)를 넣으면 계정이 생깁니다. 로그인하면 슬라이드가 교회 서버에 저장되어 다른 컴퓨터에서도 열립니다.
- **이번 주 예배**: **예배** 탭 → **예배 열기**. 콘티 PDF, 가사 파일, 설교 PPTX를 버튼으로 올리거나 창에 끌어다 놓으면 그 자리에 바로 들어갑니다.
- **Front · 날짜만 갱신**: Front는 원본 템플릿의 글자 크기·문단별 크기·텍스트 상자 위치·내용을 유지하며, 기도제목 페이지의 오른쪽 위 로고만 제외합니다. 다른 Front 페이지의 로고는 유지하고 날짜만 해당 예배 날짜로 바꿉니다. 기도제목 설정으로 Front 내용을 다시 작성하지 않으며, 자동 크기 조정과 글자 크기 통일에서도 제외합니다. 기존 기본 Front와 날짜별 Front 사본은 원본 템플릿으로 한 번 복구합니다. 보호된 자료는 자동으로 덮어쓰지 않습니다.
- **기도회 찬양 (Front 앞, 자동으로 찾기)**: 매주 기도회(기도제목 슬라이드) 전에 부르는 찬양은 **주일예배 마법사 → 4. 기도회 · 기도제목**에서 제목만 넣고 **🔎 PPT 찾기**를 누르면 됩니다. 인터넷에서 “제목 ppt”를 검색해 위쪽 결과(주로 네이버 블로그 첨부파일)에서 이름이 맞는 PPT를 내려받고, **배경 · 장식 · 로고 · 버튼은 빼고 흰 바탕에 악보와 가사 그림만** 넣은 슬라이드로 만들어 예배 맨 앞(**기도회 찬양** → Front)에 넣습니다. 다른 곡이 받아졌으면 아래 **다른 곡이면 여기서 고르세요** 목록에서 다른 파일을 고르세요. 받은 악보는 라이브러리의 **기도회 찬양 악보** 폴더에 남아서, 같은 곡은 다음에 다시 받지 않습니다. 인터넷이 필요하고 데스크톱 앱(또는 `npm start`)에서 됩니다. 구형 `.ppt`만 있는 곡은 PowerPoint 또는 LibreOffice가 설치된 컴퓨터에서 열립니다.
- **공동체 고백송**: 학기마다 · 해마다 바뀌는 고백송은 **예배** 탭 → **🙌 공동체 고백송**에서 찬양 라이브러리의 노래를 골라 저장하면 됩니다. 주일예배 Back 슬라이드의 고백송 부분이 그 노래로 바뀝니다. (한 주만 다른 노래를 쓰려면 주일예배 마법사에서 바꾸세요.)
- **발표**: **▶ 발표** 또는 F5 (처음부터), Shift+F5 (현재 슬라이드부터), Esc (끝내기). PowerPoint처럼 연결된 프로젝터·TV에 바로 전체 화면으로 뜨고 (⚙ 설정 → 출력 화면에서 고른 모니터가 있으면 그 모니터), 화면이 하나뿐이면 이 화면을 덮습니다. 발표를 끝내면 그 창도 닫힙니다.
- **어디서나 리모컨**: **⚙ 설정 → 리모컨 · 휴대폰 → 어디서나 리모컨**을 켜면 휴대폰에서 LightCast를 조작할 수 있습니다. PIN은 없고, 링크(또는 QR)를 아는 사람만 접속합니다. 링크는 교회 Worker에 한 번만 설정(`worker/remote-link.js` 안내 참고)하면 **LightCast를 다시 켜도 같은 주소**로 유지되고, **New Link** 버튼을 눌러야만 바뀝니다 (이전 링크는 즉시 막힙니다). Worker 설정 전에는 켤 때마다 바뀌는 임시 주소가 표시됩니다.
- **Behringer X32 믹서 조작 (Wi-Fi)**: X32 뒷면 ETHERNET 포트를 교회 공유기에 연결하고, 이 컴퓨터를 같은 Wi-Fi에 둔 채 **⚙ 설정 → 장비 · 연결 → Behringer X32 믹서**에서 **X32 찾기**(또는 X32 **SETUP → network**의 IP 입력 → **연결**)를 누릅니다. 연결되면 **슬라이드 쇼 → 🎚 X32 믹서 ↗**(또는 라이브 패널의 **Mixer ↗**, 메뉴 ⌘/Ctrl+3)를 누르면 믹서가 **새 창**으로 열리고, 데스크톱 앱에서는 슬라이드 쇼와 다른 프로그램 **위에 항상 떠 있습니다**(창의 **📌 항상 위**로 끄고 켭니다). 실제 X32 콘솔과 같은 모양 · 기능으로 씁니다 — **ALL**에서 X32의 모든 페이더(입력 Ch 1–32 · Aux In 1–8 · FX Return 1–8 · Bus 1–16 · Matrix 1–6 · DCA 1–8 · M/C · Main LR)를 한 번에 보고, 콘솔처럼 레이어 버튼(CH 1-16 · CH 17-32 · AUX · FX · BUS 1-16 · MTX · DCA)으로 골라 볼 수도 있습니다. 스트립마다 색 스크리블 스트립(채널 이름표) · **SEL** · **MUTE** · dB 눈금이 있는 세로 페이더가 있고, **장면 불러오기**도 합니다. **키보드**: 스트립을 누르면 선택되고, **←/→** 옆 채널 · **↑/↓** 페이더 1 dB(Shift 5 dB, Page Up/Down 10 dB) · **M** 뮤트 · **Enter** SEL. 페이더 · 노브는 위아래로 끌거나 마우스 휠로도 움직이고, 페이더를 더블클릭하면 0 dB가 됩니다. 스트립의 **SEL**을 누르면 콘솔의 SEL 화면처럼 LED 링 노브와 EQ 곡선 그래프로 **게인(트림) · 위상 반전 · 로우 컷(주파수 · 기울기) · 게이트 · 컴프레서(스레숄드 · 비율 · 니 · 어택 · 홀드 · 릴리즈 · 메이크업 게인 · 믹스) · EQ(채널 4밴드, 버스 · Main 6밴드) · 팬 · 모니터 센드(Bus 1–16)**를 조절합니다. 채널 · 버스 이름과 모든 값은 믹서에서 읽어 오고, 믹서에서 직접 바꾼 것도 바로 따라옵니다. 팬텀 전원 · 입력 배선 · 믹서 설정은 LightCast에서 바꾸지 않습니다. 매크로와 슬라이드 동작에 **X32 믹서** 동작(뮤트 · 뮤트 해제 · 페이더를 지금 값으로 · 장면 불러오기)을 넣으면, 예를 들어 설교 슬라이드가 나올 때 설교자 마이크가 자동으로 켜집니다. 데스크톱 앱에서 되며, 연결 설정은 컴퓨터마다 따로 저장됩니다.
- **성경 구절 자동 인식**: 컴퓨터의 **📖 성경** 창에서 “요한복음 3장 16절”처럼 입력하거나, 설교 원고를 붙여 넣거나 말하면 구절을 찾아 줍니다. (음성 인식은 iPad Safari · 안드로이드 Chrome에서 되고, 인터넷이 필요합니다.)
- **코드 · 키 악보**: **예배 → 🎼 코드 · 키 악보**에서 곡마다 원래 키 · **연주 키** · 카포 · BPM을 정하고, 키를 옮긴 코드(그 키에 맞는 ♭/♯ 표기)와 숫자(넘버링) 악보를 봅니다. 코드는 가사 앞에 `[G]주 은혜임을 [Em]고백하네`처럼 쓰며 청중 화면에는 나오지 않습니다. **예배 전체 인쇄 (밴드용)**으로 곡마다 한 쪽씩 인쇄하거나 PDF로 저장합니다.
- **오프라인 우선 동기화**: 슬라이드는 언제나 이 컴퓨터에 먼저 저장되므로 인터넷이 끊겨도 모든 기능을 그대로 씁니다. 맨 위 오른쪽 **☁ 계정 이름**(또는 계정 창의 **⇅ 동기화 상태**)에서 오프라인 여부, **보내지 못한 변경**, 이 컴퓨터에 아직 없는 미디어를 확인합니다. 연결이 돌아오면 자동으로 동기화하고, 서버에 닿지 않는 동안에는 점점 드물게 시도합니다. 두 기기에서 같은 프레젠테이션을 동시에 고친 경우 둘 다 남기고, **내 것 유지 · 다른 기기 것으로 바꾸기 · 둘 다 유지** 중에서 고를 수 있습니다.
- **수련회 움직이는 배경**: **수련회 만들기**의 첫 단계에서 **주제**를 넣으면 주제의 낱말(빛 · 바다 · 불 · 별 · 생명 · 은혜 …)을 보고 어울리는 움직이는 배경(빛줄기 · 물결 · 불꽃 · 별빛 · 빛망울 · 오로라)이 자동으로 정해집니다. 종류 · 색 · 속도 · 가사가 보이는 어둡기를 바꿀 수 있고, 수련회를 만든 뒤에도 **예배 → 🌌 수련회 배경**에서 주제를 바꾸면 **모든 수련회 슬라이드의 배경이 한 번에** 바뀝니다 (실행 취소 가능). 다른 프레젠테이션에도 **디자인 → 배경 서식**의 “움직이는” 배경을 쓸 수 있습니다.

## 가져온 PowerPoint 편집

- `.pptx`는 텍스트 상자·그림·도형을 개별 개체로 가져옵니다. 슬라이드를 선택한 뒤 **홈 → 내용 편집**에서 내용을 바꾸거나, 캔버스에서 개체를 선택해 이동·크기·서식을 수정하세요. 수정은 자동 저장되며 실행 취소가 가능합니다.
- 구형 `.ppt`도 편집할 수 있습니다. **데스크톱 앱**이 설치된 PowerPoint 또는 LibreOffice로 PPTX로 변환한 뒤 가져옵니다. 변환 프로그램이 없으면 안내를 표시하며 기존 자료는 유지됩니다. 브라우저에서는 먼저 PPTX로 저장해 가져오세요.
- 이전 버전에서 이미지로 저장된 PPT는 원본 개체가 남아 있지 않습니다. **홈 → 내용 편집 → PPT 원본 다시 가져오기**에서 원본 PPTX/PPT로 교체하세요. 재생목록 연결과 프레젠테이션 이름·설정은 유지됩니다. 이 작업은 해당 자료의 모든 슬라이드를 교체합니다.
- PDF는 페이지 내용이 **읽기 전용**입니다. 슬라이드 노트·발표 순서·숨기기·페이지 삭제는 사용할 수 있습니다. PPT의 특수 효과·복잡한 도형·일부 글꼴은 PowerPoint와 다르게 표시될 수 있습니다.

## 텍스트 상자 자동 크기 조정

광고·가사·가져온 PPT는 **원래 글자 크기를 유지**합니다. 내용이 적다고 글자를 키워 텍스트 상자를 채우지 않습니다. 기존의 자동 최대 크기 요청도 더 이상 실행하지 않습니다.

내용이 넘치면 먼저 **텍스트 상자의 높이를 늘리고, 필요하면 너비도 늘립니다**. 슬라이드 경계와 다른 텍스트 상자·QR 코드의 공간 안에서만 확장합니다. 사용할 수 있는 공간을 모두 써도 원래 글자 크기로 들어가지 않을 때만 글자를 줄입니다. 원래 크기를 별도로 기억하므로 내용을 줄이면 그 크기로 돌아옵니다. 서식의 **넘친 내용 맞추기**로 다시 적용할 수 있고, **넘치면 텍스트 상자 크기 조정**에서 자동 처리를 켜고 끌 수 있습니다.

같은 텍스트 상자 안에서는 문단의 글자 크기를 통일하며, 굵게·색상 등 강조는 유지합니다. 별도 상자로 나뉜 제목과 본문은 각각 크기를 정합니다. 서식의 **글자 크기 통일**로 직접 맞출 수도 있으며, 편집한 크기는 자동 저장됩니다. 가운데 정렬한 가사는 가능한 범위에서 가운데 위치를 유지합니다. PPTX 내보내기도 같은 크기·위치를 쓰며, PowerPoint가 상자를 슬라이드 밖으로 자동 확장하지 않게 저장합니다. 이전 버전에서 이미 크게 변경해 저장한 크기는 원본을 자동 추정하지 않습니다. 필요한 자료는 원본 PPT를 다시 가져오거나 글자 크기를 직접 지정해 주세요.

긴 가사 한 줄은 상자를 먼저 넓히고, 슬라이드 너비를 넘으면 같은 글자 크기로 줄바꿈합니다. PPTX 내보내기도 글자 축소 대신 상자 자동 확장을 사용합니다. 글자 크기를 유지한 내용이 슬라이드 전체보다 많으면 슬라이드를 나누어 주세요.

## 실수 방지와 필수 자료 보호

- **리모컨 발표 종료**: End 버튼을 **1초간 길게** 눌러야 종료됩니다. 진행 표시가 채워지기 전에 손을 떼거나 버튼 밖으로 이동하면 취소됩니다. 키보드 Space·Enter도 동일하며, 연결 또는 조작권을 잃으면 취소되고 재연결 때 실행되지 않습니다.
- **자료 보호**: 자료를 선택하고 **홈 → 자료 보호**를 누르세요. 라이브러리 항목 옆의 자물쇠로도 설정할 수 있습니다. 보호 중에는 슬라이드·개체 수정, 개별/전체 삭제, 파일 교체를 막고 예배 자동 정리에서도 자료와 연결된 미디어를 보관합니다. 발표와 재생목록 추가는 가능합니다.
- 수정하려면 **자료 보호 해제**를 누르고 확인하세요. 보호 설정은 기기 간 동기화되며, 보호된 자료는 이전 백업을 복원해도 보존됩니다. 보호를 설정하거나 해제하면 이전 실행 취소 기록이 초기화됩니다.
- Front/Back 같은 자동 템플릿을 보호하면 날짜·고백송 자동 갱신도 멈춥니다. 자동 갱신이 필요한 자료는 보호를 해제해 두세요. 보호는 필요한 자료에 직접 설정하는 기능이며, 기존 자료를 일괄 잠그지는 않습니다.

## 예배 준비와 점검

- **설교 PPT 교체**: 예배 탭의 설교 업로드는 선택한 예배의 기존 설교 슬라이드를 교체하고 순서·프레젠테이션 설정을 유지합니다. 여러 파일을 함께 사용할 때는 한 번에 선택하세요. 일반 파일 가져오기에서는 같은 이름으로 가져온 PPT를 제자리에서 교체합니다. 읽기 실패 시 기존 슬라이드는 유지됩니다.
- **자동 복원 지점**: 수정된 상태로 동기화를 시작할 때마다 먼저 복원 지점을 저장합니다. 변경 없는 반복 동기화는 같은 지점을 중복 저장하지 않으며, 통신이 실패해도 이미 저장한 지점은 유지됩니다. 자료 가져오기 전과 발표 시작 전에도 예배 이름을 붙여 저장합니다. **예배 → 복원 지점**에서 되돌릴 수 있습니다. 복원 지점은 현재 컴퓨터에 보관되며, 미디어를 포함한 별도 전체 백업도 권장합니다. 동기화 전 저장이 실패하면 동기화를 중단하고, 가져오기 전 저장이 실패하면 가져오기를 중단하며, 발표 전 저장이 실패하면 발표는 시작하면서 경고합니다.
- **휴대폰 연결 안내**: 리모컨에 연결·재연결·컴퓨터 종료 상태를 표시합니다. 연결이 끊긴 동안에는 조작을 막으며 자동 재연결합니다. 컴퓨터 상단에는 연결된 휴대폰 수를 표시합니다.

## 휴지통 · 리허설 · 리모컨 조작권

- **토요새벽 예배 이미지 정리**: 재생목록의 이미지 항목을 ✕로 제거하거나 재생목록을 삭제하면, 더 이상 어느 재생목록에서도 사용하지 않는 토요새벽 이미지 자료도 함께 휴지통으로 옮깁니다. 이미지 제목·폴더·슬라이드 이름·파일 이름과 토요새벽 재생목록의 이미지 자료를 인식합니다. 찬양·보호된 자료와 다른 곳에서 사용하는 자료는 유지합니다. 30일간 복원할 수 있으며, 이후 전용 미디어를 서버와 기기에서 삭제합니다. 휴지통의 **영구 삭제**로 먼저 정리할 수도 있습니다.
- **파일 → 휴지통**: 삭제한 찬양·자료·슬라이드는 미디어와 함께 30일 보관합니다. 한 번에 여러 장을 삭제했어도 **슬라이드별 복원**으로 필요한 장만 되돌릴 수 있습니다. 이후의 다른 편집은 유지하며, 전체 자료 복원 시 남아 있는 재생목록의 기존 위치에도 다시 넣습니다. 자동 정리된 예배 자료를 복원하면 `복원한 자료` 폴더에 넣어 다시 자동 삭제되지 않게 합니다. 교회 공용 찬양을 삭제한 경우 휴지통에서는 편집 가능한 로컬 사본으로 복원하며 공용 등록은 찬양 편집 창에서 다시 할 수 있습니다. 휴지통은 클라우드 로그인 중 동기화되며, 보관 중인 미디어도 서버 용량에 포함됩니다. 기간이 지나면 다음 앱 실행 또는 앱 실행 중의 정기 확인에서 정리합니다. **영구 삭제**는 실행 취소할 수 없으며, 현재 자료나 다른 휴지통 항목에서 사용하는 미디어는 유지합니다.
- **슬라이드 쇼 → 리허설**: 별도 연습 화면에서 재생목록을 선택하고 키보드·휴대폰 리모컨으로 슬라이드 진행을 연습합니다. 실제 송출 화면과 발표 기록은 그대로 유지되며 슬라이드 동작·매크로·자동 미디어 재생은 실행하지 않습니다. 연습을 종료하면 리모컨도 실제 송출 상태로 돌아옵니다.
- 상단 **휴대폰 N** 표시를 누르면 **리모컨 조작권** 창을 엽니다. 첫 휴대폰이 조작권을 받고, 나머지는 슬라이드를 볼 수 있는 보기 전용으로 연결됩니다. 휴대폰에서 **조작권 요청**을 누르면 컴퓨터에 요청 표시가 나타나며, 컴퓨터에서 조작권을 주거나 해제할 수 있습니다. 현재 조작자는 휴대폰의 **조작권 넘기기**로 다른 연결 기기에 넘길 수 있습니다. 휴대폰의 **기기** 메뉴에서 리모컨 이름을 바꿀 수 있습니다. 같은 앱/브라우저로 재연결하면 권한을 유지하며, 컴퓨터의 리모컨 서버가 재시작되면 첫 연결부터 다시 배정합니다. 컴퓨터는 항상 직접 조작할 수 있습니다.
- 업데이트 후 휴대폰 리모컨을 새로고침하면 새 기능이 표시됩니다.

## 연결 품질

- 리모컨에 **양호·지연·불안정** 및 왕복 응답시간(ms)을 표시합니다. 최근 최대 8회 측정의 지연·변동·응답 누락을 사용하며 컴퓨터의 **휴대폰 N대 연결** 창에서도 기기별 품질을 볼 수 있습니다. Wi-Fi 신호 세기나 인터넷 속도 측정값이 아니라 휴대폰에서 컴퓨터까지의 왕복 응답시간입니다.

## 기기 이름과 사용기록

- 로그인 창에서 **기기 이름**(예: 교회 본당 Mac)과 **기기 사용자 이름**을 입력하고 **기기 정보 저장**을 누르세요. 기기 ID·운영체제와 데스크톱 앱 버전·컴퓨터 이름을 표시합니다. 브라우저에서는 운영체제와 로컬 기기 ID를 표시합니다. 기기 ID와 이름은 이 앱/브라우저의 저장 공간에 보관되므로 다른 브라우저나 사용자 프로필은 별도 기기로 등록됩니다.
- 로그인하면 등록된 기기 목록과 마지막 접속 시각을 볼 수 있습니다. 이는 실시간 접속 여부를 뜻하지 않습니다. 기기 정보와 활동기록은 기존 클라우드 라이브러리를 통해 동기화되며, 각 기기의 이름 설정은 서로 바뀌지 않습니다.
- **파일 → 사용기록**에서 앱 활동과 발표·찬양 사용을 확인하고 날짜·기기·사용자·제목으로 검색합니다. 앱 활동은 최근 2,000개, 발표 사용은 최근 5,000개까지 보관합니다. 기록 당시의 이름을 남기므로 이름을 변경해도 과거 기록은 그대로입니다. 비밀번호나 로그인 토큰은 활동기록에 저장하지 않습니다.
- 교회 클라우드 라이브러리 창의 **서버 저장공간**에 실제 라이브러리 DB와 공용 자료·AI 기록 DB의 합계를 무료 계정의 Durable Objects 한도 **5 GB**(5,000,000,000바이트) 대비 사용률로 표시합니다. 데이터베이스 부가 공간도 포함하며 로그인 중에는 창을 닫아도 30초마다 갱신하고 상단 계정 버튼에도 사용률을 표시합니다. **용량 새로고침**으로 직접 조회할 수도 있습니다. 5 GB는 계정 전체가 공유하는 한도이므로 다른 Worker의 DB 사용량은 이 집계에 포함되지 않으며 계정 전체의 남은 공간을 뜻하지 않습니다. KV·R2는 별도 한도이고 로컬 복원 지점도 제외됩니다. 조회 실패 시 마지막 측정값과 오류를 표시합니다.
- 복원 지점에는 **마지막 수정 기기·사용자**와 **저장 기기·사용자**를 구분해 표시합니다. 다른 기기에서 수정한 자료를 동기화한 뒤 이 기기에서 복원 지점을 만들면 두 항목이 다를 수 있습니다. 이전 버전에서 만든 기록은 기기 정보 없음으로 표시하며, 복원 지점 자체는 각 컴퓨터에 보관됩니다.

## 재생목록 이름과 헤더

재생목록 옆 **⋯** 메뉴에 **새 재생목록 · 섹션 제목 넣기 · 이름 바꾸기 · 복사해서 새로 만들기(다음 주 예배용) · 재생목록 삭제**가 모여 있습니다. 이름은 앱 안의 입력창에 넣고 저장 버튼이나 Enter로 적용하며 Escape·취소로 닫습니다. 기존 섹션 제목의 연필 버튼이나 제목 더블클릭으로 이름을 바꿀 수 있습니다. 슬라이드의 섹션 만들기도 같은 입력창을 사용합니다.

## 개발

```bash
npm install
npm run dev        # 브라우저에서 개발 (http://localhost:5173)
npm test           # 테스트
npm run app        # 데스크톱 앱으로 실행
npm run dist       # 설치 파일 만들기 (release/ 폴더)
npm run engine     # Rust 엔진을 WebAssembly로 다시 빌드 (Rust와 wasm32-unknown-unknown 필요)
```

새 버전을 내려면 `package.json`의 버전을 올리고 설치 파일을 만든 뒤, 같은 버전 태그(`v0.1.2` 등)로 GitHub Release에 모든 설치 파일과 `latest.yml` · `latest-mac.yml`을 올립니다. 설치된 앱은 이 Release를 보고 스스로 업데이트합니다.


로그인한 사용자는 **교회 클라우드 라이브러리 → 서버 전체 자료 삭제…**에서 서버 주소·삭제 대상 수·미디어 용량을 확인하고, **본인의 로그인 비밀번호**를 다시 입력해 LightCast 자료 전체를 영구 삭제할 수 있습니다. 관리자 비밀번호는 필요하지 않습니다. 보호된 자료·재생목록·찬양·미디어·휴지통을 포함하며 공용 찬양/PPT 사이트 자료·계정·Worker 설정·고정 리모컨 링크는 유지합니다. 잘못된 비밀번호나 삭제 대상이 바뀐 경우에는 삭제하지 않습니다.

삭제 후에는 다른 기기의 로그인이 해제됩니다. 최신 LightCast에서 다시 로그인하면 서버의 빈 라이브러리로 맞추며, 이전 기기의 보호 자료나 동기화 기록이 자동으로 되살아나지 않습니다. 삭제는 실행 취소할 수 없습니다. 이 컴퓨터에 따로 내보낸 백업과 로컬 복원 지점은 서버 파일에 포함되지 않으며, 사용자가 나중에 직접 복원하는 경우에는 새 자료로 올릴 수 있습니다.
